# C. 对话输入、发送、流式与历史

## 自动化验证

```bash
cd packages/core
pnpm --config.verify-deps-before-run=false vitest run tests/turns.spec.ts tests/conversation.spec.ts tests/session-store.spec.ts tests/stats.spec.ts
```

## 用例

### C1 输入文本点击发送

- 前置条件：已连接，会话空闲。
- 操作步骤：在输入框输入文本 → 点击发送。
- 预期结果：文本出现在会话中作为 user/message；输入框清空。
- 自动化验证：无（ChatScreen 无 jest；发送逻辑在组件内）。
- 设备验证：需宿主。

### C2 运行中自动排队

- 前置条件：会话正在流式输出。
- 操作步骤：在输入框输入新消息 → 点击发送。
- 预期结果：消息进入"排队"状态，输入框 placeholder 变为"排队新消息…"；前一轮结束后自动处理。
- 自动化验证：`session-store.spec.ts` 验证 queue 帧处理。
- 设备验证：需宿主。

### C3 流式渲染

- 前置条件：模型正在输出。
- 操作步骤：观察对话区。
- 预期结果：`assistant/chunk` 增量渲染正文和 reasoning；50ms 节流不丢帧。
- 自动化验证：`turns.spec.ts` 验证 chunk 分组与 turn 推导。
- 设备验证：验证视觉效果。

### C4 发送失败回填草稿

- 前置条件：发送时网络断开或宿主报错。
- 操作步骤：发送消息 → 观察结果。
- 预期结果：草稿回填到输入框，不丢失；连接横幅提示。
- 自动化验证：无。
- 设备验证：需模拟断连。

### C5 Markdown/代码块渲染

- 前置条件：有含 Markdown 和代码块的 assistant 消息。
- 操作步骤：查看渲染结果。
- 预期结果：标题/列表/粗体/链接样式正确；代码块横向滚动；点击复制图标可复制。
- 自动化验证：`conversation.spec.ts` 验证消息结构。
- 设备验证：验证渲染效果。

### C6 历史分页加载

- 前置条件：会话历史超过一页（>50 条）。
- 操作步骤：滚动到顶部。
- 预期结果：自动加载更早记录；滚动位置不跳变。
- 自动化验证：`session-store.spec.ts` 验证 `applyHistory` 合并去重。
- 设备验证：需宿主真实长历史。

### C7 会话内搜索与跳转

- 前置条件：会话有多条消息。
- 操作步骤：点击搜索图标 → 输入关键词 → 点击结果。
- 预期结果：命中消息高亮，列表跳转到对应位置。
- 自动化验证：无。
- 设备验证：需真机。

### C8 取消生成

- 前置条件：模型正在输出。
- 操作步骤：点击"停止"按钮。
- 预期结果：发送 `session.cancel`；当前 turn 以 aborted 收尾；停止按钮消失。
- 自动化验证：无。
- 设备验证：需宿主。
