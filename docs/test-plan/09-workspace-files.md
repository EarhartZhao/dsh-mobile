# I. 工作区文件与引用

## 自动化验证

```bash
cd packages/core
pnpm --config.verify-deps-before-run=false vitest run tests/mobile-workspace.spec.ts
```

```bash
cd apps/mobile
pnpm --config.verify-deps-before-run=false jest --runInBand --testPathPattern workspace-path
```

## 用例

### I1 目录浏览

- 前置条件：已连接，会话有 cwd。
- 操作步骤：点击"+"→ 选择"文件"→ 浏览目录。
- 预期结果：面包屑路径正确；目录排在文件前；支持上级导航；刷新按钮重新拉取。
- 自动化验证：`mobile-workspace.spec.ts` 验证 listing RPC。
- 设备验证：需宿主真实文件系统。

### I2 目录截断提示

- 前置条件：目录文件数超过上限（如 200）。
- 操作步骤：浏览大目录。
- 预期结果：列表显示"已截断"提示，不渲染全部条目。
- 自动化验证：`mobile-workspace.spec.ts` 覆盖。
- 设备验证：需真实大目录。

### I3 文本文件预览分页

- 前置条件：有一个 >400 行的文本文件。
- 操作步骤：点击文件名 → 预览。
- 预期结果：首 400 行显示；"加载更多"续读下 400 行；缓存复用不重复拉取。
- 自动化验证：`mobile-workspace.spec.ts` 验证分页。
- 设备验证：验证渲染。

### I4 图片预览

- 前置条件：目录中有图片文件。
- 操作步骤：点击图片文件。
- 预期结果：以 base64 图片渲染（512KB 窗口）；非文本二进制文件显示失败提示。
- 自动化验证：无。
- 设备验证：需宿主真实文件。

### I5 Markdown 文中相对图片

- 前置条件：Markdown 文件引用同目录图片。
- 操作步骤：预览 Markdown。
- 预期结果：图片就地渲染（最多 4 张）；单张失败不阻断其余渲染。
- 自动化验证：无。
- 设备验证：需宿主。

### I6 变更流实时刷新

- 前置条件：目录浏览器打开。
- 操作步骤：在宿主端修改该目录下的文件。
- 预期结果：300ms 去抖后列表自动刷新，只刷新受影响目录。
- 自动化验证：`mobile-workspace.spec.ts` 验证变更帧。
- 设备验证：需宿主真实文件操作。

### I7 宿主机打开/定位

- 前置条件：已连接。
- 操作步骤：在文件预览中点击"打开"或"定位"。
- 预期结果：`host.openPath` 发送；宿主成功打开/定位；不支持时回显错误。
- 自动化验证：无。
- 设备验证：需宿主桌面环境。

### I8 路径复制/分享

- 前置条件：文件预览打开。
- 操作步骤：长按路径。
- 预期结果：完整绝对路径复制到剪贴板。
- 自动化验证：`workspace-path.test.ts` 验证路径处理。
- 设备验证：验证剪贴板。
